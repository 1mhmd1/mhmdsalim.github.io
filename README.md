# Mohammad Salim - Personal Portfolio

A responsive personal portfolio website showcasing my skills, projects, and professional experience.

## Features

- Responsive design that works on all devices
- Skills section with progress bars
- Resume and cover letter display
- Big Five personality test results
- Professional development plan
- Contact form

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Various JS libraries (AOS, GlightBox, etc.)

## Setup and Installation

1. Clone the repository
2. Open index.html in your browser
